# CLAUDE.md

## Descripción del proyecto
Modelo de Machine Learning para predecir el precio de viviendas en Valencia, España.
Los datos provienen de un dataset público de Kaggle sobre precios de vivienda en España.

## Estructura del proyecto
- `data/` → dataset en CSV
- `notebooks/` → análisis y modelos en Jupyter Notebook
- `src/` → funciones reutilizables

## Librerías principales
- pandas → manipulación de datos
- matplotlib y seaborn → visualizaciones
- scikit-learn → modelo de Machine Learning
- jupyter → entorno de análisis

## Convenciones
- Código en inglés, comentarios en español
- Un notebook por fase: EDA, limpieza, modelo
- Variables en snake_case

## Fases del proyecto
1. Análisis exploratorio de datos (EDA)
2. Limpieza y preprocesamiento
3. Entrenamiento del modelo predictivo
4. Evaluación y conclusiones
