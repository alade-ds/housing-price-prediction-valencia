# 🏠 Housing Price Prediction - Valencia

Modelo de Machine Learning para predecir el precio de viviendas en Valencia, España.

## 📊 Dataset
Dataset público de precios de vivienda en España obtenido de Kaggle.

## 🛠️ Tecnologías
- Python 3.14
- pandas, matplotlib, seaborn
- scikit-learn

## 🚀 Cómo ejecutar el proyecto
1. Clona el repositorio
2. Crea el entorno virtual: `python3 -m venv venv`
3. Actívalo: `source venv/bin/activate`
4. Instala las dependencias: `pip install -r requirements.txt`
5. Abre Jupyter: `jupyter notebook`
